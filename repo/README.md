# Aura Media — Aniyomi Anime Extension Repo

Aniyomi / Anikku repo with 16 SFW anime sources.

## Install
Paste this URL in Aniyomi → Settings → Browse → Extension repos → Add:

```
https://raw.githubusercontent.com/kingowow/Aura-Media/main/repo/index.min.json
```
